# 02 · Three layers — public, private, device

| Layer | What lives there | Rule |
|---|---|---|
| **Public** | the profile and this HQ: dashboard, numbers, approved chapters | only what is safe to show; **no keys** |
| **Private** | twelve stations and the parts warehouse: originals, ledger, drafts | the production line |
| **Device** | recordings, photos, personal data | never uploaded |

Decide the layer *before* creating anything. Most leaks are a file in the wrong layer.

## Say this
> "이건 어느 층이야? 공개해도 되는 것만 본사로 보내."
*(Which layer is this? Only send what is safe to show to HQ.)*
