# 07 · Issues as a database

The inbox has an issue form, *New conversation*: pick the AI, write a one-line topic, paste the conversation. A workflow turns the issue into a file in `raw/`, closes the issue with a receipt, and the line runs. No database server — the issue tracker is the input screen, git is the storage.

This HQ uses the same idea for instructions (lesson 01).

## Say this
> "입력은 이슈 양식으로 받아. 받으면 파일로 바꿔서 라인에 넣어."
*(Take input through an issue form, turn it into a file and feed the line.)*
