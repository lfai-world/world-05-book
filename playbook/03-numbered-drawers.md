# 03 · Repositories as numbered drawers

One repository = one job. Names follow the production order, so the list reads like the line itself: `world-hq`, `world-01-inbox` … `world-12-mirror`, `admin-parts`.

Every drawer carries four labels: a one-line **description**, a **README**, **topics** for search, and its **number**. Drawers that are no longer used are **archived**, not deleted — the history stays, the list stays clean.

## Say this
> "새 서랍 하나 만들어. 번호 붙이고, 설명 · README · 토픽까지."
*(Make a new drawer — numbered, with description, README and topics.)*
